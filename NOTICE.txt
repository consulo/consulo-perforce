Ported parts: the p4 command runner and output parsers, connections (settings, P4CONFIG, environment, P4V client
configuration), login and tickets, change lists and the change provider, checkout on edit, add/delete/move operations,
submit, revert, sync/update, integrate, shelve, history, annotate, diff, merge/resolve, jobs, the configurable, actions,
the localized messages and the plugin icon (converted from Kotlin to Java), and the unit tests that run without a
Perforce server.
